# Screenshots

Place dashboard screenshots here and reference them from the main README.

Suggested screenshots:
- `dashboard-overview.png` — Full dashboard with all panels visible
- `dashboard-top-sources.png` — The Top Connection Sources table showing EC2 names
- `dashboard-per-instance.png` — Per-instance detail row (current vs limit, gauge, stat)
- `alert-per-client.png` — PMM alert firing for per-client guardrail
- `alert-total-connections.png` — PMM alert firing for total connections

## How to capture

1. Open the dashboard in PMM with a specific instance selected
2. Use your browser's screenshot tool or PMM's "Share → Snapshot" feature
3. Crop to show just the relevant panel(s)
4. Save as PNG in this directory
5. Reference in the main README as `![Description](screenshots/filename.png)`
